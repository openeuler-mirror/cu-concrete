# cu-concrete GUI

基于 PyGObject (GTK3) 的插件化图形界面。**不修改**现有 TUI/CLI/策略源码。

## 唯一入口

```bash
cd 2512/cu-concrete
python3 gui/main.py                 # 主界面，加载全部插件
python3 gui/main.py --plugin shell.harden   # 单独运行某一插件
python3 gui/main.py --list          # 列出已发现插件
```

## 目录

- `core/` 宿主核心
- `adapters/` 策略/API 适配层
- `plugins/shell/` 主流程壳功能
- `plugins/policy/` 策略项插件
- `plugins/api/` API 能力插件
- `plugins/utility/` 帮助中心、导入导出等配套
- `config/` GUI 自身配置
